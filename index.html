Moss v0.1 Reference Manual

1 - Introduction

Moss is an efficient scripting language intended for beginners and designed to teach the fundamentals of computer programming. It is object-oriented and compiled just-in-time for performance.

The reference implementation is IronMoss, which is open-source and programmed in Rust. Its source is available in the Moss Github Repository held under the MIT License.

2 - Basic Concepts

2.1 - Types

Moss has the following primitive types:

  • str (strings)
  • bool (booleans)
  • int32 (32-bit signed integers)
  • int64 (64-bit signed integers)
  • fl32 (IEEE754 single-precision floating points)
  • fl64 (IEEE754 double-precision floating points)
  • u32 (32-bit unsigned integers)

Most primitive types in Moss produce first-class values. These values can be stored in bindings, passed as arguments, and returned as results. The u32 type is an exception; its values are third-class and cannot be stored, passed, or returned. All types are nullable.

2.1.1 - Strings (str)

Strings are immutable sequences of up to 4,294,967,296 (232) UTF-8 characters. Each character is given an index under the u32 type, starting at 0 and incrementing by 1. Strings can be defined with either single quotes or double quotes ('string' or "string"). Double quotes are standard.

// String example
let x = "Hello World!"
// Index: 0 = H, 1 = e, 2 = l...

// Get a specific index as a string
let y = x.index(1)
// y == "e"

2.2 - Variables & Constants

Moss has two kinds of bindings: variables and constants.

Bindings need to be declared and given an initial value in order to be used throughout a scope. Declaration uses the keywords let for variables and const for constants. null is not a valid literal to declare with.

// Declaration
let variable = 5
const CONSTANT = 10

Moss uses static typing. Once a binding is declared, its type is fixed and cannot be changed. Any literal assigned to a binding must be compatible with the binding's declared type.
